This is a GitHub repository for the project "Trait selection and use in avian functional diversity research" by Facundo Palacio and Marta Jarzyna. 
The paper reviews 501 peer-reviewed articles on avian functional diversity research, synthesizing the topics addressed, trait selection strategies, data sources, analytical approaches, and ecological rationales underlying trait-based analyses. 
It identifies major research themes—including community assembly, conservation, and responses to global change—evaluates geographic, taxonomic, and trait-specific biases, and examines patterns of trait integration, including recurrent trait combinations and potential gaps in trait representation.

The repo contains an avian_traits.Rproject file, with code to run the analysis and create figures, and the database as both avian_traits_database.csv and avian_traits_database.xlxs files.
